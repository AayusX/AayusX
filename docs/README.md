## Instructions for coding agents

- Read the relevant documentation before implementing a feature.
- Inspect the existing repository before changing its architecture.
- Do not invent personal information, project achievements, testimonials, or statistics.
- Do not replace authentic assets with generated approximations.
- Keep the implementation responsive, accessible, and performant.
- Test meaningful changes before calling them complete.
- Update the status document when implementation decisions change.

If a requirement cannot be completed without owner input, record it in `IMPLEMENTATION_STATUS.md` instead of fabricating it.
